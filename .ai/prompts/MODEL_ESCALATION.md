# Model Escalation Prompt

Use before requesting a more expensive model or higher reasoning effort.

```text
AI/token cost is a first-class project requirement.

Before escalation, try:
1. reduce loaded context
2. retrieve only targeted files
3. reuse already verified information
4. decompose the task
5. use deterministic tools/scripts
6. ask for a narrower human decision

If still insufficient, stop and ask explicitly:
- what escalation is requested
- why it is needed
- what cheaper alternatives were already tried
- what scope the escalation applies to

Do not change model or reasoning effort automatically.
```
